Delivery qualification rules
  • FIRST FILTER — full NSE Main Board: Every symbol in the official Main Board universe is evaluated, not only stocks passing a prior 5-session screen.
  • Listing condition: Symbol must be present in the current official NSE Main Board Equity Master (EQ/BE/BZ universe).
  • Data condition: All 5 sessions must have valid NSE EOD Bhavcopy data; stale or incomplete data is flagged, not treated as a pass.
  • 30-day Delivery Cycle A: At least 5 rolling windows of 5 consecutive NSE EQ sessions must each average ≥60% delivery. Any window with missing data does not pass.
  • 30-day Delivery Cycle B: At least 5 individual EQ sessions must each have delivery ≥60%.
  • 30-day first-filter gate: A OR B passes. Cycle A needs at least 5 rolling 5-session windows averaging ≥60%; Cycle B needs at least 5 individual sessions at ≥60%. Exactly 60% qualifies.
  • Liquidity review: Latest-session traded volume below 1,000 shares is marked REVIEW only; it does not automatically remove the stock.
Source: NSE official EOD Bhavcopy + NSE Equity Master. 30-day window is anchored to the latest validated EOD session. This is a research filter, not a buy/sell signal.

This page displays NSE Bhavcopy delivery data. It is not a buy/sell recommendation.

Low-volume review is a display-only heuristic (below 1,000 shares in the latest session); it does not remove a stock from results. Main Board membership is checked against NSE’s official Equity securities CSV. If that file cannot be verified, results are marked unverified rather than assumed.

Fundamental metrics are intentionally not displayed until official NSE filing values pass the repository's validation and approval process. A blank fundamental cache must not be replaced with Yahoo/free-source estimates.
